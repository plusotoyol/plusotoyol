# PLUS OTOYOL

Türkiye'deki yolculuk deneyimini geliştirmek için; yollar, otoyollar, köprüler, tüneller, otoyol ücretleri, akaryakıt, yol bilgileri, yol duyuruları, son dakika gelişmeleri ve bilgi içerikleri gibi ulaşım verilerini tek bir platformda bir araya getiren ulaşım teknolojileri projesidir.

## Başlangıç

```bash
nvm use && npm install
npm run dev:backend    # ayrı terminalde
npm run dev:frontend
```
